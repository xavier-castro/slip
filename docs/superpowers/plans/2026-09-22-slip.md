# Slip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install a local Slip binary whose floating notes are markdown files in the Obsidian vault folder `floating_notes`.

**Architecture:** Start from Karatasi commit `7764ca9d4e600b30bdcc905e19ca8627f06f3294`, drop the website and release packaging, rename the process and window identity to Slip, and point the default notes directory at `~/Documents/xavier-obsidian/floating_notes`. Hyprland loads `hypr/slip.lua`.

**Tech Stack:** Tauri 2, Rust, Vite, TipTap, Omarchy Hyprland Lua.

**Spec:** `docs/superpowers/specs/2026-09-22-slip-design.md`

## Global Constraints

- Source commit: `7764ca9d4e600b30bdcc905e19ca8627f06f3294`
- MIT license and Hemal's copyright notice stay
- Binary `slip` at `~/.local/bin/slip`
- Tauri identifier `local.xavier.slip`
- Window class `slip`; titles `Slip`, `Slip - <note title>`, `Slip Search`, `Slip Tiled`
- Config `~/.config/slip/config.toml`; socket `$XDG_RUNTIME_DIR/slip.sock`
- Env `SLIP_SCOPED`, `SLIP_MEMORY_MAX` (default `1500M`), `SLIP_DEBUG`
- Default notes directory `~/Documents/xavier-obsidian/floating_notes`
- Welcome note id `welcome-to-slip`, written only when the folder has no notes
- Delete `site/`, `wrangler.toml`, `scripts/deploy-site.sh`, `scripts/release.sh`, `.github/workflows/release.yml`, `packaging/`
- Super+N toggles; Super+W hides Slip when it is focused and still closes other windows; autostart `slip start`
- Images stay in `floating_notes/assets/`
- A `notes_dir` value in the config file overrides the default

## Review Focus

- Wayland class may follow `productName` rather than the identifier. A person expects Super+N to float and pin the window. Pin this by checking `hyprctl clients` after launch and matching both the Lua rules and the Rust class checks to the class that is actually set.
- A note rename from Slip does not rewrite Obsidian wikilinks. A person who linked `[[old-slug]]` from a daily note expects that link to follow the rename. The spec leaves this out of scope; do not add a rewriter.
- Obsidian and Slip can save the same file. A person expects one save on each side to settle, not a rewrite loop. The watcher must ignore read events.
- `systemd-run` missing must log and keep Slip running.
- An empty title still names the file `untitled` and does not trash a blank note.

- [ ] **Step 2: Write `hypr/slip.lua`** by adapting `packaging/karatasi.lua` from the pinned tree:

```lua
local toggle_key = slip_toggle_key or "SUPER + N"
local close_key = slip_close_key
if close_key == nil then close_key = "SUPER + W" end
local autostart = slip_autostart
if autostart == nil then autostart = true end

o.bind(toggle_key, "Notes: toggle Slip", "slip toggle")

if close_key then
  hl.unbind(close_key)
  o.bind(close_key, "Close window (hides Slip)", function()
    local window = hl.get_active_window()
    if window and window.class == "slip" then
      hl.dispatch(hl.dsp.exec_cmd("slip hide"))
    else
      hl.dispatch(hl.dsp.window.close())
    end
  end)
end

o.window({ class = "^slip$", title = "^Slip Search$" }, {
  tag = "-default-opacity",
  opacity = "1 1",
  float = true,
  pin = true,
  size = { 680, 440 },
  center = true,
  border_size = 1,
})
o.window({ class = "^slip$", title = "^Slip Tiled$" }, {
  tag = "-default-opacity",
  opacity = "1 1",
  float = false,
})
o.window({ class = "^slip$", title = "^Slip( - .*)?$" }, {
  tag = "-default-opacity",
  opacity = "1 1",
  float = true,
  pin = true,
  size = { 960, 720 },
  center = true,
  focus_on_activate = false,
})

if autostart then
  o.launch_on_start("slip start")
end
```
